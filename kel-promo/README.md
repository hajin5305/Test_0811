## 지킨 기준 (브리프 2·6·7·9장)

- **결승 8팀을 확정으로 표현하지 않았습니다.** 결승 진출 칸은 이름 없이 "DIRECT" 4칸과 "?" 4칸으로 표시하고 "준결승 후 확정"을 붙였습니다.
- 팀명은 브리프 표의 공식 국문 표기 그대로이며, 긴 이름도 줄이지 않았습니다.
- 집결 장면에는 "시즌 참가 16팀 전체"라고 범위를 적었습니다.
- 팀 로고, 선수 얼굴, 게임 지도, 경기 장면을 AI로 만들지 않았습니다. 로고 모양의 그래픽도 만들지 않았습니다.
- 도 단위 연고(경기·강원·충남·전남·경북·경남·제주)는 도 전체 영역을, 광역·특별자치시는 해당 시 영역을, 시 단위 연고(고양·성남·양주)는 핀으로 강조합니다. 제주와 울릉도·독도도 포함됩니다.
- 공통 키프레임 값: 텍스트 등장 18f(+28px → 0), 핀 등장 24f(한 번 강조 후 정지), 대한민국 확대 48f(100% → 145%), 루미아 섬 100% → 120%, 음악 120 BPM(1박 30f).

## 최종 공개 전에 확인할 것

1. **결승 8팀 확정 후(11월 7일 준결승 이후)**: 결승 구조 장면의 "?" 4칸과 집결 장면을 최종 명단으로 바꿀지 결정합니다. 바꾸면 범위 표기도 "결승 진출 8팀"으로 바꿉니다.
2. **루미아 섬 지도**: 대회 적용 최신 지도로 바꾸려면 `assets/img/`의 파일을 교체하고 `src/main.js`의 파일명과 출처 문구를 고칩니다.
3. **팀 로고**: 공식 투명 로고를 확보하면 팀 카드 오른쪽 위에 넣을 수 있습니다. `index.html?placeholders=1`로 열면 `[TEAM_LOGO]` 자리가 보입니다.
4. **시청 안내**: 중계 채널이 공식 발표되면 마지막 화면의 "자세한 안내 · playeternalreturn.com" 줄을 채널명으로 바꿉니다. 지금은 확인되지 않은 채널명을 넣지 않았습니다.
5. 일정이나 장소가 바뀌면 `src/main.js`의 문구(대회 소개, 결승 장소, 일정 장면)를 함께 고칩니다.

## 실제 경기 클립을 넣는다면

이 영상에는 클립 기록(clip_id, source_vod_url, source_in/out, region_confirmed 등)에 올릴 실제 경기 클립이 없습니다.
클립을 확보하면 다음 자리에 편집 도구에서 덮어쓰는 방식을 권장합니다.

- 01:04 직전 루미아 섬 구간(00:56–01:04): 오른쪽 지도 패널 자리에 위치가 확인된 교전 3–4초
- 01:48–01:56 집결 구간: 팀 이름 벽 뒤 배경으로 하이라이트 몽타주 (이름 벽은 반투명 유지)
- 위치가 확인되지 않은 클립(region_confirmed = false)은 특정 지역 핀 없이 지도 전체에서 연결합니다.

## 미리보기와 다시 렌더하기

```bash
# 미리보기 (음악 포함, 스페이스바 재생/정지, ←/→ 3초 이동, ?t=초 로 특정 시점)
npx serve .            # 또는 python3 -m http.server
# 브라우저에서 http://localhost:3000/index.html

# 수정할 곳
src/timeline.js              # 구간 시각, 팀 소개 순서, 효과음 시각
src/main.js                  # 장면별 문구와 움직임
scripts/build_korea_map.py   # 팀명·연고·좌표 → src/korea_map.js 생성
scripts/make_audio.py        # 음악과 효과음 → audio/kel_promo_mix.wav

# 다시 만들기 (Node 18+, Playwright Chromium, ffmpeg, Python3 + numpy/scipy)
python3 scripts/build_korea_map.py
python3 scripts/make_audio.py
node scripts/render.mjs --workers 3          # out/kel_championship_final_promo.mp4 (마스터)
ffmpeg -i out/kel_championship_final_promo.mp4 -vf hqdn3d=0:0:6:6 -c:v libx264 -preset medium -crf 21 \
  -c:a copy -movflags +faststart out/kel_championship_final_promo_web.mp4   # 공유용
node scripts/stills.mjs out/stills 8.3 33 98  # 특정 시점 정지 화면 확인
```

모든 움직임은 `renderFrame(t)` 한 함수가 시각만으로 계산하므로, 미리보기와 렌더 결과가 프레임 단위로 같습니다.
필름 그레인은 렌더 속도를 위해 ffmpeg 단계(`noise` 필터)에서 넣습니다.
